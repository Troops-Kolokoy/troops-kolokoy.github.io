Setup checklist

  1. MT5 for Windows on a PC or VPS that stays on. The phone MT5 app can't run bots.
  2. Put JS_Gold_Session_EA.ex5 in MT5 → File → Open Data Folder → MQL5 → Experts.
  3. Tools → Options → Expert Advisors → tick Allow WebRequest and add the 3 addresses below.
  4. Turn on Algo Trading, attach the bot to XAUUSDm M30, paste your licence key.
  5. Recommended: Risk 1%, max lot 0.05 (lower for a small account).
